# 📇 Friend-Box App

**Friend-Box App** — это удобное приложение для создания и управления карточками с информацией о друзьях, коллегах или знакомых. Оно помогает хранить все важные данные в одном месте и быстро находить нужного человека.  

## ✨ Основные возможности

- 📝 **Создание карточек**  
  Добавляйте карточки с подробной информацией о человеке:
  - ФИО  
  - Год рождения  
  - Место работы или учебы  
  - Контакты (телефон, email, Telegram)  
  - Фото (аватарка)  

- 🔄 **Редактирование и обновление**  
  Легко изменяйте данные в карточках, если информация устарела или появилась новая. 
- ❌ **Удаление карточек**  
  Удаляйте ненужные карточки одним действием.  
- 🔤 **Сортировка по алфавиту**  
  Все карточки автоматически отображаются в алфавитном порядке для удобного поиска.  

## 🎯 Для чего это приложение

- Хранение контактов друзей и коллег в структурированном виде  
- Быстрый доступ к информации о человеке  
- Удобная замена бумажным записным книжкам или разрозненным заметкам
